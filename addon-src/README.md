# 年龄限制游戏时长，多结局版（基岩版转制）

未成年人保护模组 · Minecraft Bedrock Addon

> 本 Addon 为 Java 版模组 **Minor Safety Mod v1.0.0**（Forge 1.20.1，作者 SereneCloud）的基岩版二次开发转制版。
> 已获原作者授权进行二次开发，采用 **MIT** 许可证，保留原作者署名。
> 二次开发：**ET（ET协会）**

## 功能（与原版 1:1 复刻）

| 功能 | 说明 |
| --- | --- |
| 身份验证 | 进世界强制弹出表单，填写**姓名 + 年龄**（原版 `/verify` 指令逻辑） |
| 未成年人限时 | 年龄 < 18：限玩 **5 分钟**，HUD 顶部实时显示剩余时间 |
| 到时锁定 | 时间耗尽后锁定移动/跳跃/挖掘/攻击，弹出"游玩时间已结束" |
| 我已长大 | 锁定界面点击「我已长大」重新验证（原版 TimeUpScreen 逻辑） |
| 成人多结局 | 年龄 ≥ 18：按年龄段弹出**趣味提示**，从 18 岁一直幽默到 LUCA（共 56 个结局文案） |
| 数据持久化 | 姓名/年龄/剩余时间存档（动态属性，对应原版 players.json） |
| 验证令牌 | 进世界自动发放「验证令牌」物品，右键即可打开验证界面 |
| 聊天指令 | 输入 `/verify`、`/minorsafety`、`/msverify` 或 `!verify` 打开验证（指令兜底） |

## 兼容性

- **推荐：Minecraft 基岩版 1.20.60 ~ 1.26+**（Script API 稳定版）
- 更早版本（1.2.x ~ 1.19）无法运行：脚本功能（表单/计时/锁定）依赖 Script API，1.2.20 时代尚无 Addon 脚本系统，故物理上无法兼容，特此说明。

## 安装

1. 下载 `年龄限制游戏时长，多结局版.mcaddon`
2. 用 Minecraft 基岩版打开该文件（或手动导入世界/全局资源）
3. 进入世界，自动弹出身份验证表单，完成验证即可

  - `RP/` 资源包（文本/贴图）

## 隐私与安全

- 仅记录玩家自填的姓名/年龄到本地动态属性，不上传任何数据。
- 未成年人限时与锁定为本地客户端逻辑，适合家长监管单机/局域网场景。
