# 网易版（中国版基岩）部署说明

## 重要背景（根因）
网易我的世界**中国版基岩版不支持国际版的 JavaScript Script API（@minecraft/server）**。
此前上传的国际版行为包（含 `scripts/main.js`）在网易**脚本不会运行**，因此没有倒计时、没有时间到提示——这是用户实测问题的根本原因。

网易中国版基岩的正确开发方式是 **Python ModSDK（mcstudio）**。本目录提供完整可用的 Python 模组工程。

## 目录结构
```
netease-py-mod/
├── mod/                 # Python 模组（核心逻辑）
│   ├── mod.json         # 模组描述（名称/版本/入口/版权）
│   ├── main.py          # 入口：注册服务端系统
│   └── ageLimitServer.py# 服务端系统：验证/倒计时/锁定/多结局
├── behavior/            # 行为包（已移除 scripts，仅数据，供网易识别）
├── resource/            # 资源包（图标/语言文件）
└── README-网易部署.md
```

## 核心功能（服务端实现）
| 功能 | 实现 |
|---|---|
| 强制验证 | 玩家进世界提示「!验证 姓名 年龄」（聊天指令，示例：`!验证 小明 12`） |
| 未成年人 5 分钟倒计时 | 服务端每秒 TickOnce 倒数，Tip 提示「剩余游玩时间：4:59」 |
| 时间到锁定 | slowness+mining_fatigue+weakness 效果锁定移动/挖掘/攻击 |
| 时间到提示 | Tip 醒目提示 + 聊天栏红色提示，持续存在 |
| 成人多结局 | 56 档年龄区间趣味文案（与 Java 版完全一致） |
| 数据持久化 | 服务端 CreateData 组件保存姓名/年龄/剩余时间/状态 |

## 上传到网易平台（开发者工作台）
1. 登录 https://mcdev.webapp.163.com → 上架与资源管理 → 手机版资源 → **新建「模组」类型资源**（不要选 add_ons）。
2. 资源名称：**年龄限制游戏时长，多结局版**；定价：免费；二次开发如实标注（MIT + 原作者 SereneCloud）。
3. 将本目录打包为 zip（顶层含 `mod/`、`behavior/`、`resource/`），按《中国版资源上传规则》上传。
4. 组件图标/轮播图/视频可复用 `netease_assets/` 目录下素材。
5. 提交审核前建议用 **MCStudio** 新建基岩工程导入本代码，核对引擎 API（个别 API 名随版本调整）；若 MCStudio 报错，把日志发回，我来修正。

## 玩家使用方式（进游戏后）
- 进世界后屏幕提示验证 → 聊天框输入 `!验证 姓名 年龄`
- 未成年人：`!验证 小明 12` → 开始 5 分钟倒计时，时间到自动锁定并提示
- 成年人：`!验证 老王 30` → 弹出对应年龄的多结局趣味文案，正常游玩
